# Task Management System

A Python project built to practice Software Engineering,
Object-Oriented Programming, SOLID Principles, and Software Testing.

## Features

- Create and manage tasks
- Manage projects and their tasks
- Manage users
- Update task status
- User registration
- Repository abstraction
- Logging and exception handling
- Unit testing with Pytest

## Setup

Clone the repository:

```bash
git clone https://github.com/fidelazzouz/task-management-system.git
cd task-management-system
```

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

Install Pytest:

```bash
python3 -m pip install pytest
```

## Run the Application

```bash
python3 main.py
```

## Run Tests

```bash
python3 -m pytest -v
```

## Logging

Application logs are stored in `app.log`.
